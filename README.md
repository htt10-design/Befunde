# Befunde

Mess- und Befundblätter für Motoren als offline-fähige Web-App (PWA) – im gleichen Design wie **Zettel-Job**.

**So geht's:** Auftrag anlegen → Motor eintragen (z.B. `16V 4000 M63` → V-Motor, 16 Zylinder, A1–A8/B1–B8) → Blätter hinzufügen → ausfüllen → drucken / als PDF speichern.

Blätter (je Baugruppe als **Messblatt**, **Befundblatt** oder **beides**):

| Baugruppe | Blätter |
|---|---|
| Allgemein | Allgemeines Befundblatt (Durchsicht, Checkliste, Feststellungen mit Fotos) · Seriennummern Bauteile (HD-Pumpen 1–x, Förderpumpe, Turbolader, LLK, Pleuel, KW-Pumpe, Seewasserpumpe, Zylinderköpfe, SÖ-Pumpe, eigene) |
| Zylinder & Brennraum | Endoskopie (Bild mit A-/B-Reihe, Zählweise ab KS/KGS) · Kolbenüberstand |
| Laufbuchse | Laufbuchse (Ø in 3 Ebenen, Ovalität, Konizität + Sichtbefund) · Einpassen (Gehäuse ↔ Buchse, Spiel) · Überstand (4 Punkte, Nachbarvergleich) |
| Kurbelwelle | Lagergasse (Grundlagerbohrung, Fluchtung) · Zapfen (Grund- & Hublager) |
| Nockenwelle | Nockenwellenlager (Bohrung ↔ Zapfen, Lagerspiel) |
| Einspritzung | Düsen abdrücken (Öffnungsdruck, Strahlbild, Dichtheit, Schnarren) |

- Sollwerte eintragen → Messwerte werden sofort grün / gelb / rot bewertet; Sollwerte je Motortyp merken
- Schnelleingabe: bei Nennmaß 170,000 reicht `23` für 170,023
- Befunde mit Fotos auf jedem Blatt, Gesamtbewertung, Unterschrift Prüfer/Kunde
- Druck: einheitlicher Kopf auf allen Blättern, optional Deckblatt mit Übersicht & Handlungsbedarf
- Aufträge aus Zettel-Job übernehmen (wenn beide Apps unter derselben Adresse laufen, z.B. GitHub Pages)
- Sicherung / Auftrag als Datei (inkl. Fotos), Hell/Dunkel

Starten: Ordner über einen beliebigen Webserver ausliefern (z.B. GitHub Pages) und im Handy-Browser „Zum Startbildschirm hinzufügen“.
